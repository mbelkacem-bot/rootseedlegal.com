📤 Mettre à jour votre site Root & Seed Legal

Guide pas-à-pas · Sans terminal · Via GitHub uniquement

⚡ Important à comprendre

Votre site est connecté à GitHub. Netlify surveille GitHub et redéploie automatiquement dès qu'un fichier change. Vous n'avez pas besoin de toucher à Netlify — il suffit de mettre à jour les fichiers sur GitHub.

Étape 1

📁 Décompressez le ZIP reçu

Sur votre ordinateur, trouvez le fichier rootseedlegal-deploy.zip téléchargé.

Double-cliquez dessus pour le décompresser. Vous obtenez un dossier avec tous ces fichiers :

  • index.html
  • lexibot.html
  • uhnwi.html
  • espace-client.html
  • cgu.html
  • mentions-legales.html
  • guide-administration.html
  • robots.txt
  • sitemap.xml
  • netlify.toml
  • _redirects
⚠️ Ne glissez pas le dossier complet — uploadez les fichiers individuellement dans GitHub.
Étape 2

🌐 Ouvrez votre dépôt GitHub

Allez sur :

https://github.com/mbelkacem-bot/rootseedlegal.com

Vous verrez la liste de vos fichiers HTML, comme dans un explorateur de fichiers.

Étape 3

⬆️ Uploadez les fichiers — méthode rapide

Sur la page de votre dépôt GitHub, cliquez sur :

Add file → Upload files

Une page s'ouvre avec une zone de glisser-déposer.

Glissez tous les fichiers HTML du dossier décompressé directement dans cette zone (index.html, lexibot.html, uhnwi.html, etc.)

Attendez que tous les fichiers soient chargés (barre verte = 100%).

Étape 4

💾 Validez (Commit changes)

Tout en bas de la page, vous verrez une section "Commit changes".

Dans le champ texte sous "Commit changes", écrivez par exemple :
Mise à jour mobile responsive

Puis cliquez sur le bouton vert Commit changes.

Étape 5

⏱️ Attendez le déploiement automatique

Netlify détecte automatiquement les changements sur GitHub et redéploie votre site en 30 à 60 secondes.

Pour vérifier que c'est fait :

Allez sur app.netlify.com → votre site → onglet Deploys → le dernier déploiement doit afficher Published en vert.
Étape 6

📱 Testez sur votre téléphone

Ouvrez votre site sur votre iPhone ou Android.

⚠️ Si vous voyez encore l'ancienne version, c'est le cache du navigateur. Pour forcer le rechargement :
Safari iOS : Réglages → Safari → Effacer l'historique et les données du site → rechargez

Chrome Android : appuyez longtemps sur le bouton recharger → "Vider le cache et recharger"

Ou testez en navigation privée (aucun cache).
